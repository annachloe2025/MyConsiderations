    冷風機の検討からエアコン買い替えへ：PC冷却と室内環境の意思決定¶

    きっかけ¶

    夏に向けて、エアコンだけだと部屋の涼しさを保てないので 冷風機を買おうか と考えていた。値段・電気代・効果を調べるうちに、

    1. 「冷風機」には全然違う3タイプの製品が混在している
    2. 本当の目的は PCの温度を下げること （2026-05-14_RTX3090の続き）
    3. 冷風機はその目的に一番向いていない選択肢 だった
    4. 自分のエアコンは 20年超 なので、冷風機より買い替えが合理的
    5. 勝間和代の家電論 （エアコンは専業メーカー一択、電気代は食わない）が決定打になった

    最終的に 「冷風機は買わない。PC内部清掃（0円）＋20年超エアコンの早めの買い替え」 という結論に至った意思決定プロセスのメモ。出発点（冷風機）からずいぶん遠いところに着地した。

    学んだこと¶

    「冷風機」の3タイプ（取り違え注意）¶

    「冷風機」という言葉には全然違う製品が含まれていて、取り違えると「買ったのに全然涼しくない」後悔につながる。

    タイプ 仕組み 冷却力 価格 電気代 注意点
    冷風扇 水・氷の気化熱で風を冷やす ほぼなし（扇風機の風が少し冷たい程度） 5,000〜15,000円 月数百円 湿度が上がる、エアコンの除湿と相性悪い
    卓上クーラー（ペルチェ） 半導体冷却、顔まわりピンポイント 部屋全体は冷やせない 8,000〜15,000円 月数百円 デスクワーク中の局所冷却用
    スポットクーラー エアコンと同じコンプレッサーで本当に冷気を作る 広範囲で効率的 25,000〜60,000円 エアコンに近い 排熱ダクトを窓外に出さないと部屋が逆に暑くなる

    電気代が安い冷風扇は「ほとんど冷えていないから安い」とも言える。スポットクーラーはエアコン並みに電気を食う。

    冷風機がPC冷却に向かない理由¶

    PCの温度を決めるのは 「室温」そのものよりケース内のエアフロー 。冷風機を部屋に置いても、PCケースの中まで冷気は届かない。

    さらにタイプ別に問題：

    • 冷風扇 ：気化熱で 室内の湿度が上がる 。湿度はPCに良くない（結露・ホコリの固着・電子部品の劣化リスク）
    • スポットクーラー ：冷気と同時に 排熱を出す 。排熱ダクトを窓外に出さないと部屋全体ではむしろ熱がプラスされる

    「部屋全体を下げないとPCも下がらない」という推測は正しいが、その手段として冷風機を選ぶと 湿度や排熱で逆効果 になりやすい。

    PC温度を下げる優先順位（室温と別軸）¶

    デスクトップの良いところは 内部に手を入れられる こと。室温を下げる前に、ここで稼げる余地が大きい。

    1. 内部のホコリ除去（0円〜エアダスター代） ：古いPCはファン・ヒートシンクにホコリが詰まり、これだけで CPU/GPU温度が5〜10℃下がる ことも。最優先
    2. ケースファンとエアフロー（数千円） ：基本は「前下から吸気、後ろ上から排気」
    3. 設置場所 ：壁・家具にぴったり寄せると吸排気が阻害される。数cmの余裕、床置きはすのこで浮かせる
    4. サーマルペーストの劣化（古いPCなら） ：何年も使うとグリスが乾く。塗り直しで改善するが慣れが必要なので最後

    → PC（5年弱）なら サーマルペーストはまだ機能している可能性が高く、まず内部清掃で様子を見る段階 。5年分のホコリで温度がはっきり下がる見込み。

    部屋全体の冷却：8畳には10畳用が適正¶

    8畳の部屋には 10畳用（2.8kW）クラス が適正。「8畳だから8畳用（2.5kW）」だとギリギリで、古い建物・西日・PCという発熱源がある状況では力不足になりがち。

    PCは常時100〜300W前後の「小型ヒーター」として部屋を温め続けている ので、ワンサイズ上を選ぶと安心。

    エアコン買い替えの費用構造¶

    「本体＋標準工事＋（必要なら）追加工事」の3層：

    項目 目安
    本体（10〜14畳用・スタンダード） 8〜14万円
    標準取付工事 1.5〜2万円（量販店では本体価格に含むことも）
    旧エアコン取り外し・リサイクル 3,000〜6,000円
    専用回路がない場合の増設工事 1.5〜3万円
    100V↔200V切り替え工事 数千円

    10畳用スタンダード機を工事込みで 9〜14万円 程度。省エネ上位機なら15〜20万円。

    「専用コンセントの法律」の正体¶

    「エアコンの隣にコンセントの口を作らないといけない法律ができた」という記憶は少しズレている。

    • これは 法律で義務化されたものではない （経産省Q&Aでも法令上の義務はないと明記）
    • 根拠は 内線規程という民間規格 。定格電流10Aを超える据置型は専用分岐回路を設けることとされる
    • 厳格に守られるようになったのは 2000年ごろから 、新しい法律ではない
    • エアコンが既に付いている家なら、おそらく既に専用コンセントはある。買い替えなら新規工事は不要なケースがほとんど

    空気清浄機能付きエアコンは目的にコスパが悪い¶

    検討したが、結論は不要：

    • エアコンの空気清浄機能は ピンキリで中身がかなり違う （イオン放出程度の簡易的なものから単体空気清浄機並みまで）
    • 空気清浄機能はPC冷却にも部屋を冷やす力にも一切寄与しない 。冷却能力（kW）は同じで価格だけ上乗せ
    • 「ちゃんとした空気清浄が欲しい」なら 独立した空気清浄機（1〜3万円）を別に買うほうが性能も上で総額も安い ことが多い

    → 加湿器を使っているので、空気清浄を新エアコンに求める強い理由はない。 冷却が目的なら空気清浄なしスタンダード10畳用で十分 。

    2026年モデルの10畳用エアコン¶

    価格帯別：

    • エントリー〜スタンダード（7〜11万円） ：ダイキンEシリーズ、パナソニックEolia Jシリーズ、三菱霧ヶ峰GEシリーズ、日立白くまくん普及シリーズ。冷房能力は上位機と同じ2.8kW、8畳を冷やす実力に不足なし
    • ミドルクラス（12〜18万円） ：センサー・内部乾燥機能などの「快適さ」付加価値。冷やす力そのものは変わらない
    • 型落ち品 ：1年前のモデルが新品で安く買える。基本性能に問題ないことがほとんど、コスパ重視なら有力

    選ぶ指標は APF（通年エネルギー消費効率）と省エネ基準達成率 。20年前の機種からの買い替えなら、ここの差が電気代に効く。

    買うタイミング¶

    • エアコンがお得なのは 暑さを感じる前の3〜4月 、型落ち品もまだある
    • 6月以降は買い替える人が増え、設置まで1か月以上かかることも
    • 20年超のエアコンはいつ止まってもおかしくない 。猛暑日に故障してから手配すると工事待ちで何日も冷房なしになりかねない
    • 5月中旬の今は、梅雨明けの繁忙期前に動くのが賢明

    勝間和代のエアコン論（決定打）¶

    家電歴40年・2000以上を自腹で試してきた勝間和代の見解（『仕事と人生を変える 勝間家電』）。

    1. メーカーは空調専業メーカー一択¶

    勝間は普段「家電のメーカー指名買いは無意味」という立場だが、 エアコンだけは例外 。圧縮機（コンプレッサー）や冷媒を含む空調機器の心臓部を自社で設計・製造している ダイキン・三菱・日立の専業メーカー一択 。

    優先順位：可能な限り ダイキン → 選べなければ三菱か日立。

    理由は 故障率と耐久性 。量販店では弱電メーカー系（シャープ・パナソニック）が安く見えるが、故障が多かったり冷え・暖まりが悪かったりするため、何割か高くてもコンプレッサー・室外機の技術蓄積のあるメーカーを選ぶべき。

    → 20年使うことを考えるなら特に効いてくる視点 。

    2. エアコンは意外と電気代を食わない¶

    エアコンは冷蔵庫と並んで電気を食う家電と思われがちだが、実はそれほど消費しない。仕組みの話で、 電気そのものを熱に変えるのではなく、外気の熱エネルギーを移動させる熱交換方式（ヒートポンプ） だから。

    → 「電気代を怖がってエアコンを我慢する」のは非合理。

    3. 設定温度¶

    夏は27度、冬は21〜22度が効率的に適温を得られる目安。

    4. 湿度管理は加熱式加湿器で¶

    室内湿度を40%以上に保つことを勧め、加湿器は超音波式より きっちり加熱して殺菌できる加熱式一択 。

    5. スポット暖房はセラミックファンヒーター¶

    人がいない時間が多い仕事部屋ではエアコンの効率が悪いので、人感センサー付きセラミックファンヒーターを椅子のそばに置く使い分け。

    自分なりの解釈¶

    結論：冷風機は買わない¶

    意思決定の最終形：

    1. PC内部を清掃（ほぼ0円） ：5年分のホコリ除去。これでPC温度が解決する可能性が十分高い
    2. 今のエアコンのフィルター掃除（0円） ：20年機でもいくらか改善
    3. エアコンは年齢的に延命より買い替えを軸に ：専業メーカー（ダイキン第一候補）の空気清浄なしスタンダード10畳用、工事込み8〜12万円
    4. 冷風機（2〜6万円）は選択肢から完全に外れた

    この意思決定で見えた構造¶

    1. 「出発点の選択肢」が間違っていた¶

    出発点は「冷風機を買おうか」だったが、 目的（PC冷却＋部屋冷却）に立ち返ると冷風機はどの優先順位にも入ってこない 。

    • PC冷却 → ケース内に冷気が届かない、冷風扇は湿度でむしろ不利
    • 部屋冷却 → 8畳に対して力不足、スポットクーラーは排熱問題

    「何を買うか」より先に「本当の目的は何か」を確定させると、検討していた選択肢自体が消える 。これは過去エントリの「合理性で判定するモード」の典型的な作動。目的関数を明確にすると、最初の選択肢が最適でないことが計算できる。

    2. 費用対効果の階段¶

    対策 費用 効果
    PC内部清掃 ほぼ0円 CPU/GPU温度 -5〜10℃
    エアコンフィルター掃除 0円 効きが戻る
    サーキュレーター 3,000〜8,000円 冷気を循環
    エアコン買い替え 8〜14万円 確実だが高額
    冷風機 2〜6万円 どの目的にも決め手にならない

    2026-05-14のRTX3090記事で見た 「無料の対策が一番効く」 という傾向がここでも再現された。0円のPC清掃を先に試すのが手堅い。

    3. 専門家の知見で判断軸が一段上がる¶

    勝間和代の家電論を参照したことで、判断軸が「冷却能力」だけから 「故障率・20年使う耐久性」 に拡張された。

    • 自分の「スタンダードクラスで十分」（冷却能力の話）は正しい
    • 勝間の「専業メーカー一択」（耐久性の話）を足すと、 「専業メーカー × スタンダードグレード」の交差点 が最適解になる
    • 具体的にはダイキンEシリーズ、三菱霧ヶ峰GEシリーズ、日立白くまくん普及シリーズの10畳用（工事込み8〜12万円）

    これは過去エントリの 「知識量が増えると同じ対象から取り出せる情報が増える」 （5/4）の実例。勝間の知見という新しいスキーマを足すことで、エアコン選びの解像度が上がった。

    4. 「我慢して補う」より「根本を効率化する」¶

    勝間の「エアコンは電気代を食わない」「冷蔵庫と並んで誤解されている」という指摘が、最初の出発点を直撃した。

    「エアコンだけだと涼しさを保てないから冷風機を」と考えていたが、 古くて効きの落ちた20年もののエアコンを我慢して使い続け、冷風機で補おうとするより、効率の良い専業メーカーの新しいエアコンに替えてしっかり使うほうが、電気代の心配は要らず、結果的に快適で合理的 。

    これは 「制約を別のもので補う」より「制約の根本を効率化する」 という構造。冷風機（補助）に金を使うより、エアコン（根本）を更新する。

    これも過去エントリの 「新ハードを買うより既存ハードを最適運用」（5/14）の逆パターン として興味深い。5/14ではGPUは「買い替えず最適運用」が正解だったが、エアコンは「20年超なので買い替えが正解」。 同じ「効率化」の判断でも、対象の年齢・劣化度で結論が逆になる 。RTX3090（4年9ヶ月、まだ使える）とエアコン（20年超、寿命超過）の差。

    残された問い・次の作業¶

    1. PC内部清掃後の温度実測 ：5年分のホコリ除去でどこまで下がるか
    2. エアコン買い替えの実行 ：5月中（繁忙期前）に量販店で見積もり、コンセント形状の写真を持参
    3. 専業メーカー × スタンダードの具体選定 ：ダイキンEシリーズ等の実機比較
    4. 加湿器が加熱式かの確認 ：勝間推奨は加熱式。超音波式なら衛生面で買い替え検討
    5. 長期的な室内環境管理 ：CO2（2026-04-14_室内ウォーキングと空気質）と温度・湿度をセットで管理する
