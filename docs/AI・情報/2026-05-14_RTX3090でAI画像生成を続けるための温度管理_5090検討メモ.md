# RTX3090でAI画像生成を続けるための温度管理：5090検討メモ

## きっかけ

ローカルでAI画像生成（Stable Diffusion、Flux等）を続けているが、 **RTX 3090 を酷使すると壊れるのか** が気になった。手元の3090は購入から4年9ヶ月、修理歴あり。AI画像生成は **GPU使用率が常に95〜100%に張り付くタイプの負荷** なので、ゲームより明らかに厳しい。

調べていく中で：

1. 3090固有の **VRAM過熱問題** （構造的弱点）が深刻
2. 実測すると **VRAM温度102℃** という危険ゾーンに入っていた
3. **MSI Afterburnerでパワーリミットを80%** にすることで一気に安全圏に落とせる
4. 「速度がほしいなら5090検討」も視野に入れたが、 **現在60万円のプレミアム価格で待ち推奨**

最終的に **「3090をいたわって使い続ける」** という結論に至った実用メモ。

## 学んだこと

### 3090固有の構造的弱点

3090は発売当時から「熱設計に余裕がない」と言われていたカード。具体的な弱点は2つ：

#### 1. VRAMの過熱問題

- 24GB GDDR6Xメモリを **基板の表と裏に配置**
- 特に **裏面のVRAMはサーマルパッドだけで冷却**
- AI画像生成はVRAMを激しく使うので、ここが **100℃を超えやすい**
- GDDR6Xの耐熱は110℃前後、超えるとサーマルスロットリング
- 長期的にはメモリチップやハンダの劣化を早める

#### 2. ファンとサーマルパッドの経年劣化

- 24時間生成し続けるような使い方をすると、ファンベアリングが1〜2年で異音を出し始める
- サーマルパッドも乾燥・硬化して熱伝導が落ちる

### AI画像生成の負荷特性

ゲームと違って、AI推論は **GPU使用率が常に95〜100%に張り付く** タイプの負荷。これがゲームより厳しい理由は **休む瞬間がないこと** 。ゲームならローディング画面や戦闘の合間に温度が下がるが、バッチ生成ではずっと全開。

### VRAM温度の確認方法：HWiNFO64

タスクマネージャーでは **GPUコア温度しか見られず、本当に危険なVRAMジャンクション温度は見えない** 。

**HWiNFO64** （hwinfo.com からダウンロード、無料）が定番ツール。

#### 手順

1. インストール後、起動時のダイアログで **「Sensors-only」** を選択
2. センサー一覧から **「NVIDIA GeForce RTX 3090」** のセクションを探す
3. 以下の3項目を確認：
   - **GPU Temperature** ← コア温度
   - **GPU Hot Spot Temperature** ← 最熱点
   - **GPU Memory Junction Temperature** ← **VRAM温度（最重要）**
4. 各項目の右側の Current / Min / **Max** / Avg の **Maxを見る**

#### 数値の目安

| VRAM温度 | 状態 |
|---|---|
| 〜85℃ | 余裕あり |
| 85〜95℃ | 普通の範囲、問題なし |
| 95〜100℃ | **やや高め、対策推奨** |
| 100〜105℃ | **危険水域** |
| 105℃〜 | サーマルスロットリング発生、寿命に影響 |

GPUコア温度が70〜80℃台で問題なくても、 **VRAM温度だけ100℃超え、というのが3090あるある** 。

### 実測：102℃でやや危険ゾーンだった

実際にHWiNFO64で測ってみた結果：

| 項目 | 現在 | 最大 | 評価 |
|---|---|---|---|
| GPU温度（コア） | 83.4℃ | 84.5℃ | 普通（問題なし） |
| **GPU Memory Junction** | **100.0℃** | **102.0℃** | **⚠️ 高い** |
| GPU Hot Spot | 98.9℃ | 100.2℃ | ⚠️ 高い |
| GPU電力 | 329W | 347W | ほぼフルパワー（350W） |

**VRAM 102℃は安全動作範囲（〜110℃）の上限ギリギリ** 。即故障はしないが、長期間使うと寿命を縮める。 **既にサーマルスロットリング（性能低下）が起きている可能性もある** 。

### 対策の優先順位（効果が大きい順）

#### 🥇 最優先：パワーリミットを80%に下げる

**MSI Afterburner** （msi.com、無料）で設定。

- パワーリミット 100% → 350W
- パワーリミット **85% → 約298W**
- パワーリミット **80% → 約280W**
- パワーリミット 70% → 約245W

**VRAM温度が10〜15℃下がることが多い** 。生成速度は **5%程度しか落ちない** （体感ほぼ変わらない）。

#### 🥈 すぐできる対策：エアフロー改善

- **PCケースの側面パネルを開ける** （応急処置だが効果絶大、10℃前後下がることも）
- **サーキュレーターか扇風機を直接当てる** （冗談みたいだが本当に効く）
- ケース内のホコリ・ケーブル整理
- 室温を下げる（夏場は致命的）

#### 🥉 長期対策

- **サーマルパッド交換** （VRAM温度を15〜20℃改善、分解が必要で自己責任）
- ケースファン追加

### サーキュレーター直当ての注意

GPUの冷却で重要なのは **「風量」であって「冷たい風」ではない** 。GPUのヒートシンクは室温との温度差で熱を逃がす仕組みなので、 **25℃の風がたくさん当たるほうが、20℃の弱い風より効く** 。

#### おすすめ機器

| 機器 | 効果 | 価格 | 推奨度 |
|---|---|---|---|
| サーキュレーター | ◎ 風量大・直進性 | 3,000〜8,000円 | ★★★★★ |
| 扇風機 | ○ 効果あり | 3,000〜10,000円 | ★★★★ |
| 冷風機（気化式） | △ 湿度上がりPC的に逆効果 | 1〜3万円 | ★★ |
| スポットクーラー | ○ 効くが大型 | 3〜8万円 | ★★ |
| エアコン | ◎ 部屋全体が涼しくなる | - | ★★★★★ |

#### 設置のコツ

1. PCケースの側面パネルを開ける（超重要）
2. サーキュレーターを **GPU直撃の角度** にセット
3. **30〜50cmの距離** で当てる
4. **強風モード** で運転

これで **VRAM温度が5〜10℃下がる** ことが多い。パワーリミット80%と組み合わせれば、 **102℃ → 85〜90℃** くらいまで落ちる可能性がある。

#### やってはいけないこと

- **冷風機（気化式）を近くで使う** ：湿度が上がってPC内部に湿気がたまる → 長期的に基板が劣化
- **冷えすぎを狙ってエアコン直当て** ：結露の原因（夏場の急冷で特に）
- **PCの真上から当てる** ：ホコリが舞ってPC内部に入り込む

### MSI Afterburner設定の手順

#### 1. ダウンロードとインストール

msi.com/Landing/afterburner/graphics-cards から「DOWNLOAD AFTERBURNER」。ZIPファイル（約60MB）→展開→`MSIAfterburnerSetup.exe`を実行。

RivaTuner Statistics Server も一緒にインストールしておく（あったほうが便利）。

#### 2. Power Limit スライダーを80に

起動後、画面中央のスライダー群から **「Power Limit (%)」** を探す。デフォルト100。

- スライダーを左にドラッグして **80** にする
- または数値を直接クリックして 80 と入力

#### 3. Apply ボタンを押して適用

#### 4. プロファイルに保存

「Save」ボタン → 「1」をクリック → プロファイル1に保存。

#### 5. 自動起動の設定（重要、これをやらないと再起動で100%に戻る）

歯車アイコン → 「General」タブ：

- ✓ Start with Windows
- ✓ Start minimized

「Profiles」タブ：

- 2D profile と 3D profile を両方「1」に設定
- ✓ Apply overclocking at system startup

これで **再起動しても自動で80%リミットが適用** される。

### 効果の目安（3090でAI画像生成）

| パワーリミット | 生成速度 | VRAM温度 | 消費電力 |
|---|---|---|---|
| 100% | 100% | 高い | 350W |
| **85%** | 95〜97% | -5〜8℃ | 約298W |
| **80%** | 92〜95% | -8〜12℃ | 約280W |
| 70% | 85〜90% | -15℃前後 | 約245W |

**85%が一番コスパ良い** 。速度はほぼ犠牲にならないのに、温度と電力がしっかり下がる。

### ソフトの×ボタンを押した時の挙動

#### HWiNFO64

- ×を押すと **完全に終了** する
- 計測が止まるだけ、PCには何の影響もない
- **必要な時だけ起動するのが普通の使い方** 、常駐不要

#### MSI Afterburner

- ×を押しても **タスクトレイに最小化されて動き続ける**
- **パワーリミット80%の設定を維持し続けるために常駐が必要**
- 完全終了したい場合はタスクトレイのアイコンを右クリック → Exit（やると100%に戻る）

#### 効いているかの確認方法

HWiNFO64で画像生成中の **GPU電力（GPU Power）** を見る：

- 約280W前後 → **80%リミット効いてる** ✅
- 340〜350W → リミット効いてない（再設定）

### 5090検討：性能は怪物級だが今は買い時ではない

純粋にスループット向上が目的で5090を検討したが、結論は **「今は買い時ではない」** 。

#### 基本スペックの比較

| 項目 | RTX 3090 | RTX 5090 |
|---|---|---|
| アーキテクチャ | Ampere | Blackwell |
| VRAM | 24GB GDDR6X | 32GB GDDR7 |
| メモリ帯域 | 936 GB/s | 1,792 GB/s |
| CUDAコア | 10,496 | 21,760 |
| TDP | 350W | **575W** |
| 製造プロセス | Samsung 8nm | TSMC 4nm |
| 電源コネクタ | 8pin x2 | **12V-2x6（新規格）** |

#### AI画像生成での速度

- 3090比で **2〜2.5倍速**
- 3090が1枚10秒なら5090は3〜4秒
- VRAM 32GBでFluxの大型モデルやSDXLの高解像度バッチも余裕

#### 5090固有の懸念

1. **消費電力が桁違い** ：TDP 575W（3090の1.6倍以上）。電源1000W以上推奨、夏は暖房器具レベル、電気代も増える
2. **12V-2x6コネクタの発熱問題** ：4090で発生した12VHPWRコネクタの溶解問題が、5090でも報告されている。575Wが1本のコネクタに集中するので、わずかな接触不良でも溶解
3. **VRAM温度はむしろ改善** ：GDDR7は発熱特性が改善、85〜95℃に収まることが多い
4. **価格が暴騰中** ：定価39万円のカードが市場価格50〜60万円

#### 2026年5月時点の市場状況

- 新品最安値 約63万円、中古でも57万円前後
- 2025年10月頃からDRAM価格高騰の影響で在庫薄
- 12月17日時点で即納在庫なし、価格50万円超
- 2026年1月下旬に在庫が戻り始めたが、価格は60万円に迫る水準
- メモリ供給は2026年後半から改善の可能性

#### 速度向上の選択肢比較

| 選択肢 | 3090比の速度 | 追加コスト | VRAM |
|---|---|---|---|
| 現状維持（3090最適化） | 1.0〜1.2倍 | 0円 | 24GB |
| **RTX 4090 中古** | **1.6〜1.8倍** | **20〜30万円** | 24GB |
| RTX 5090 新品 | 2.0〜2.5倍 | 60万円+ | 32GB |
| 3090をもう1台追加 | 並列で2倍 | 8〜12万円 | 24GB×2 |

**速度目的に絞るなら、5090より4090中古のほうがコスパ圧倒的に良い** 。

#### GPU買い替え前にやるべきこと

3090で速度を最適化しきれていない可能性も。やってない設定があれば、買い替えなしで20〜30%速くなる：

- **xformers / sdp attention の有効化** ：SDXLで20〜30%高速化
- **TensorRT変換** ：SD1.5/SDXLで最大2倍（対応モデル限定）
- **fp8 / bf16 の活用** ：Flux系で速度大幅改善
- **--medvramを外す** ：VRAM足りてるなら不要、速度が落ちる
- **バッチ生成の活用** ：1枚ずつより効率的

## 自分なりの解釈

### 結論：3090をいたわって使う

実際にやったこと：

1. **MSI Afterburnerでパワーリミット80%に設定** （プロファイル1に保存、自動起動オン）
2. **HWiNFO64で定期的にVRAM温度を確認** （×で閉じて必要時だけ起動）
3. **サーキュレーター直当て** （これから夏に向けて実施予定）
4. **5090は当面見送り** （価格落ち着くまで待つ、メモリ価格は2026年後半改善見込み）

### この経験で見えた構造

#### 1. AI画像生成という負荷の特殊性

ゲーマー視点のGPU管理（コア温度を見る、サーマルスロットリングだけ警戒）では足りない。 **AIワークロードは「VRAMを連続フル稼働させる」** という、ゲームとは違うストレスをかける。だから：

- VRAMジャンクション温度の監視が必須
- パワーリミットの効果が劇的（速度ほぼ落とさず温度大幅改善）
- 夏場の室温管理が直接的に寿命に効く

これは「ローカルでAIを動かす」時代特有の新しいハードウェア管理パターン。

#### 2. 「無料の対策が一番効く」という傾向

| 対策 | 費用 | 効果 |
|---|---|---|
| MSI Afterburnerでパワーリミット80% | 0円 | VRAM温度 -10〜15℃ |
| PCケース側面パネル開放 | 0円 | -5〜10℃ |
| サーキュレーター直当て | 5,000円 | -5〜10℃ |
| サーマルパッド交換 | 数千円＋分解スキル | -15〜20℃ |
| 5090買い替え | 60万円 | 速度2倍だが温度問題は形を変えて残る |

**0円で最も効果が大きい** （パワーリミット）。費用対効果のグラフは極端で、安い対策から順にやるのが理にかなっている。

#### 3. 新ハード購入を急がない判断

過去エントリの **「テクノロジーが構造的に有利な扉を開ける」** （5/4のAI、5/9のAudible）と同じ構造で、 **「新ハードを買う」より「既存ハードを最適に運用する」のほうが費用対効果が大幅に良い** ことが多い。

特に：

- 価格高騰期に焦って買わない（2026年後半の値下げ可能性）
- 自分の用途に4090中古で十分だと気づく
- 現状3090でやれる最適化を全部試してから判断する

これは過去エントリの **「中級どまり問題」** （5/1）の解とも整合する：高い投資より、自分の認知特性とツール特性の組み合わせを最適化するほうが、結果としてアウトプットを増やす。

### 残された問い・次の作業

1. **パワーリミット80%設定後のVRAM温度実測** ：102℃ → 88〜92℃に落ちる予測。検証する
2. **サーキュレーター導入後の追加効果** ：夏前に実施
3. **xformers / TensorRT等のソフトウェア最適化** ：速度向上の余地がどこまであるか確認
4. **5090買い替えの判断材料** ：2026年後半の価格動向、自分の用途で本当に必要な機能（VRAM 32GB？速度2倍？）
5. **長期で本格的にAI画像生成を続けるなら** ：5090ではなく、出てくるかもしれない5080 Super / 6000番台を待つ選択肢
