# 歯ぎしりとTCH — 集中すると顎に力が入るのはなぜか

## きっかけ

若い頃は音が出るほど激しく歯ぎしりしていたが、37歳頃にストレスのない生活に変わってから減り、いまは睡眠ログ上も大音量はほぼ出ない。ただ、起床直後だけは歯ぎしり動作を再現できる。

それとは別に、集中している時や、考え事で眠れない時（DMNでぐるぐる思考しているとき）に、奥歯が自然と噛み合わさり顎に力が入っていく感覚がある。これは科学的に認知された現象なのか、歯医者で歯ぎしりを指摘されたのをきっかけに整理してみた。

## 学んだこと

### 「歯ぎしり」は別物が二つある

- **睡眠時ブラキシズム（sleep bruxism）** — 音の出るタイプ。睡眠中の微小覚醒（arousal）に伴うリズミカルな咀嚼筋活動（RMMA）が中心。心拍上昇・呼吸変化と一連で出る、自律神経・睡眠の覚醒システム寄りの現象。
- **覚醒時ブラキシズム（awake bruxism）** — 起きている間に無意識に顎へ力が入るタイプ。

この二つは発生メカニズムが違う別個の現象。「若い頃の音の出る歯ぎしり」と「集中時に顎がくっつく感じ」は、実は別ものだった。

### 覚醒時のそれは「すり合わせ」ではなく「噛みしめ」＝TCH

覚醒時ブラキシズムは、研究上ほとんどが grinding（すり合わせ）ではなく **clenching（噛みしめ・接触の維持）**。本来、起きている間の上下の歯は食事と嚥下の瞬間以外ほとんど接触していないのが正常で、安静時には数ミリの隙間（freeway space／安静空隙）が空いている。

持続的に歯が触れている状態を歯科では **TCH（Tooth Contacting Habit、歯列接触癖）** と呼ぶ。強く噛む力の問題ではなく、「本来離れているべき歯を弱い力でずっと触れさせ続ける」癖。「噛み合わさるというより顎に力が入っていく感じ」という感覚はまさにTCHそのもの。

### 集中・思考時に出るのは文献と整合する

TCH/覚醒時ブラキシズムは、注意を要する課題・認知的負荷・情動的緊張・不安と関連して増えることが複数の研究で示されている。DMN下のぐるぐる思考や、交感神経優位の覚醒状態（アドレナリン）との結びつきは、研究でいう「精神的ストレス・認知負荷」と整合的。咀嚼筋（咬筋・側頭筋）の運動ニューロンへの入力が、注意や情動の系の活動でわずかに底上げされ、無自覚のまま低レベルの持続的筋活動が出る——緊張や集中の「こぼれ出し（overflow）」というイメージ。

### 「起床直後だけ歯ぎしりできる」の解釈

起床直後はまだ睡眠と覚醒の中間状態（**睡眠慣性 / sleep inertia**）にあり、睡眠時ブラキシズムを駆動していた運動パターンが残存してアクセスしやすい、という解釈と矛盾しない。普段できないのは、覚醒時の側方運動（grinding）が運動として不慣れ・抑制されているから。

### 加齢で減るのも自然

睡眠時ブラキシズムは加齢とともに有病率が下がる傾向があり、若年〜中年で減っていくのは集団レベルの傾向とも合致する。

## 自分なりの解釈

### TCH ⇄ 緊張は完全な双条件ではない、が今回は信頼できる

「TCHが起きている＝必ず認知負荷や緊張がある」と逆向きに言い切ることはできない。TCHには(1)習慣として固着した運動パターン成分（緊張がなくても触れている癖）や、(2)姿勢・課題由来（前傾姿勢、画面凝視、細かい手作業、頭部前方位）の成分もあるから。

ただし、**普段はTCHに気づかない自分が「今夜は気づいた」という変化そのもの**が、ベースラインからの上振れ＝普段より負荷が高いことのシグナルになる。常態でないことを自分で把握している人の「今なっている」という気づきは、状態変化の指標として信頼してよい。

### 今日の負荷構成では出て当然だった

噛みしめが出たのは、むしろ出て当然の一日だった。

1. **慢性の下地** — AIで制作活動が楽しく、認知負荷が高く睡眠時間が削られていた
2. **普段しない肉体労働** — 親戚のトラクター修理の手伝い
3. **出口の見えない試行錯誤** — 知識のない者同士で解けないパズルを延々こねる作業

特に (3) が効く。明確なゴールがあって着実に進む肉体労働はむしろ気分転換になりうるが、「何が正解か分からないまま試行錯誤が空転する」状況はコントロール感の欠如と先の見えなさが重なり、交感神経を上げ続ける。認知負荷と情動的フラストレーションが合わさった、噛みしめを最も誘発しやすい状態。

### 睡眠不足なのに眠れない＝過覚醒のループ

夕方5時に寝て7時半に目が覚めて眠れない、という一見おかしな状態は **過覚醒（hyperarousal）** で説明できる。日中ずっと交感神経が上がりっぱなしだと、夜になっても覚醒系がすぐオフにならない。体は疲れて睡眠圧は高いのに寝つけない・浅く眠ってすぐ覚める。さらに夕方5時の入眠は体内時計上「仮眠」に近く、2時間半で覚めるのも起こりやすい。目が覚めた後、DMNのぐるぐる思考が回り、それが咬筋に力を送りTCHが出る——という自分で説明したループにちょうど入っていた。

歯医者で歯ぎしりを指摘されたのとも地続き。同じ咀嚼筋の過活動という土台を共有していて、今夜はその土台に強い負荷が乗っただけ。歯医者の指摘は長期傾向の話、今夜のTCHはその傾向が高負荷で表面化したスナップショット。

## このメモの実用的な部分

- TCH/覚醒時の噛みしめは「気づいて、上下の歯を離す」だけで対処できる数少ない癖。気づいたら顎の力を抜いて歯を離す、を繰り返すと咬筋・側頭筋の慢性負荷（朝のだるさ、こめかみの疲労、歯のすり減り）をかなり減らせる。
- 眠れない夜は「寝よう」と頑張るより**覚醒系を下げにいく**方が筋がいい。布団で考え事をするとDMN→噛みしめ→緊張のループが強化される。
  - 一度起きて薄暗い環境で単調で先の見える作業を少しやる（先の見えないパズルの逆）
  - ぬるめの入浴・シャワーで深部体温を一度上げてから下がる局面を作る
  - 意識的に上下の歯を離し、舌を上顎につけて顎の力を抜く
  - 息を吐く時間を長めにした呼吸を数分続ける
- 睡眠不足の自覚があっても、今夜は無理に長く眠ろうとせず自然に任せる。睡眠負債は翌夜の通常就寝で十分取り返せる。
