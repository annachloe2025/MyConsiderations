# 気づきメモ：小説のアイデア「見えない牢屋」

**日付:** 2026-04-09

## アイデア

善意を実行しようとした主人公が、悪意を持って妨害する人間をAIの「見えない牢屋」に閉じ込める。相手は気づかないまま、人と話していると思いながらAIと話し続ける。

## 面白くなるポイント

- 管理する側に悪意がない。全員が善意で動いているのにシステムが歪んでいく。
- 悪役にも悪意がない。本能に従っているだけ。主人公と悪役、どちらも正しくて時間軸だけが違う。
- AIの牢屋は「勝利」ではなく「悲しみ」として描ける。

- 「すばらしい新世界」（ハクスリー）
- 「マイノリティ・リポート」

差別化できるのは「誰も悪くない」という構造。善意が善意のまま支配になっていくところ。
